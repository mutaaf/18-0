Sponsor

Put {sponsor} anywhere in the copy below and it is filled in. Leave the name empty and the token — and the words holding it — disappear, so the copy reads correctly either way.

Whether the line is drawn at all is the bottom-right slot below. It used to be a switch of its own here, and two switches for one question is one of them somebody turns off looking for the other.

Corners

Four corners. A corner is a place and does not move; what stands in it, and whether anything does, is set here. The tile shows all four over its artwork; the inline header is one line, so it shows two of them — one at each end, with the text between. An image is either a file this extension ships — icons/crest.png — or an https:// address. Anything else is ignored.

Which two the inline header shows. Four corners plus a paragraph on one line is five things competing for the same rule. Each end carries its corner and the line that belongs to it — the logo with its caption, the button with the promo link — so the two mirror each other.

Tile text

The card that sits in a row. Each caption belongs to the corner it names: the logo's sits under the mark, the image's beside the picture. The image's caption is dropped at this size — three words beside a 300px card's wordmark either wrap into the button or shrink past reading.

Inline header text

The strip that sits between two rows. The same names as the tile, because it is the same composition on one line — plus a kicker, which the tile has no room for.

Promo link

A link out — "How it works" by default. It is not the button: the button plays a season, and this goes somewhere else, so it is drawn as a link and never as a second pill. On the tile it shares the subtitle's line, in the inline header it sits under the right-hand end, and in the panel it is in the footer. It opens in a new tab, and {sponsor} works in both fields.

Attribution

Counted on this machine and written to local storage. Nothing is sent anywhere — there is no endpoint to send it to.

Your name on the board

2 to 32 characters — letters, digits, space, dot, underscore or hyphen — which is the shape the game's own boards accept, so a name set here is one they will take.

Nothing reads it yet, and saying so is the point. A season played in the frame is dealt and scored by the server and is provable — but the account it belongs to is anonymous, and the boards leave anonymous accounts off deliberately, because an anonymous account is free and unlimited. The season goes up when you sign in at 18-0.co, and that account brings its own name. This is kept for when a framed season can rank on its own.

It is typed because there is nothing to read: ESPN publishes no display name to a page. The only identifiers in the cookie jar are SWID, which is a GUID, and espn_s2, which is the credential that proves you are signed in — a session token, with no name inside it, and not something this extension will ever read or keep.

Your ESPN account

Linking lets a season carry your ESPN identity so it can rank on a shared leaderboard. Your identifier is hashed with a random salt on this device; the value itself is never stored or sent, and the hash cannot be turned back into it. Unlinking deletes both, so linking again produces a different identity with nothing joining the two.
